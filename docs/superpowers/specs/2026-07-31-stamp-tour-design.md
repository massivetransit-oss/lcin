# 부평바로알기 스탬프투어 설계

## 목적
카카오맵 기반으로 부평 지역의 스탬프투어 장소를 보여주고, 사용자가 실제로 해당 장소 근처에 있을 때만 인증사진과 코멘트를 남길 수 있게 한다. 모든 장소를 인증하면 완료 화면을 보여준다.

## 범위
- 이름 + 4자리 PIN 기반 간이 계정 시스템 (Supabase Auth 미사용)
- 카카오맵에 장소 마커 표시, 마커 클릭 시 장소 상세로 이동
- GPS 거리 검증(100m 이내)을 통과해야 인증사진 업로드 + 코멘트 작성 가능
- 장소당 인증은 1회만 인정
- 인증사진/코멘트는 장소별로 전체 공개
- 모든 장소를 인증하면 완료 화면 표시

## 아키텍처
별도 백엔드 서버 없이, 기존에 세팅된 Vite + React + TypeScript 앱이 `@supabase/supabase-js`로 Supabase Postgres/Storage에 직접 접근한다.

- 인증(계정)은 Supabase Auth를 사용하지 않고, `users` 테이블을 클라이언트에서 직접 조회/삽입하는 방식으로 구현한다. 로그인 성공 시 `{id, name}`을 `localStorage`에 저장해 재방문 시 자동 로그인한다.
- **보안 트레이드오프**: Supabase Auth 기반 RLS(행 단위 보안)를 사용하지 않으므로, anon key를 가진 누구나 이론적으로 테이블을 직접 수정할 수 있다. 이는 캐주얼한 지역 서비스 범위에서 허용하기로 확정한 트레이드오프이며, 추후 필요 시 Supabase Auth 익명 로그인 + RLS로 전환할 수 있다.

## 데이터 모델 (Supabase Postgres)

### `users`
| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid, pk | |
| name | text, unique | 표시 이름, 중복 불가 |
| pin | text | 4자리 숫자 PIN |
| created_at | timestamptz | |

### `places`
| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid, pk | |
| name | text | 장소명 |
| description | text | 장소 설명 |
| address | text | 주소 |
| lat | double precision | 위도 |
| lng | double precision | 경도 |
| order_index | int | 스탬프북 표시 순서 |
| created_at | timestamptz | |

초기 데이터는 부평 지역 예시 장소 3~5곳(실제 좌표는 추후 Supabase 대시보드에서 직접 교체)을 시드로 넣는다.

### `visits` (스탬프 기록)
| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | uuid, pk | |
| user_id | uuid, fk→users | |
| place_id | uuid, fk→places | |
| photo_url | text | Storage 공개 URL |
| comment | text | |
| created_at | timestamptz | |

`(user_id, place_id)` 조합에 unique 제약을 걸어 장소당 1회만 인증되도록 한다.

### Storage
- 버킷 `visit-photos`: 공개 읽기 가능, 인증사진 업로드용.

## 화면 구성

### 1. 로그인 화면
- 이름 + 4자리 PIN 입력 폼
- 이름이 `users`에 없으면 새 계정으로 생성(PIN 저장)
- 이름이 있으면 PIN 일치 여부 확인 후 로그인
- 이름은 유일해야 하므로, 이미 존재하는 이름에 다른 PIN을 입력하면 오류 표시
- 성공 시 `{id, name}`을 `localStorage`에 저장

### 2. 지도 화면
- 카카오맵 JS SDK로 전체 장소를 마커로 표시
- 이미 스탬프를 받은 장소는 마커 스타일로 구분
- 마커 클릭 → 장소 상세 화면으로 이동

### 3. 장소 상세 화면
- 장소 정보(이름/설명/주소) 표시
- 브라우저 `navigator.geolocation`으로 현재 위치를 가져와 장소 좌표와의 거리를 계산
- 100m 이내일 때만 인증사진 업로드 + 코멘트 작성 폼 노출
- 100m 밖이면 "장소 근처에서만 인증 가능합니다" 안내와 함께 남은 거리 표시, 폼은 비활성화
- 이미 해당 장소를 인증했다면 폼 대신 "이미 인증 완료" 배지 표시
- 하단에 해당 장소에 남겨진 모든 사용자의 인증사진/코멘트 목록을 전체 공개로 노출

### 4. 스탬프북 화면
- 전체 장소를 그리드로 보여주고 각 장소의 수집 여부를 표시
- 모든 장소를 다 모으면 완료 화면(예: "모든 스탬을 모았습니다!") 표시. 별도의 보상/쿠폰 발급은 없음

## 에러 처리
- PIN 불일치: "이름 또는 PIN이 올바르지 않습니다" 인라인 에러
- GPS 권한 거부/미지원: "위치 정보를 허용해주세요" 안내 + 재시도 버튼
- 거리 초과(100m 밖): 남은 거리를 표시하며 인증 폼 비활성화
- 이미 인증한 장소 재방문: 인증 폼 대신 "이미 인증 완료" 배지, 기존 사진/코멘트만 노출 (재인증 불가)
- 사진 업로드 실패(네트워크 등): 에러 메시지 + 재시도 버튼

## 테스트
현재 프로젝트에는 자동화 테스트 러너가 없으며, 이번 스코프에서도 추가하지 않는다. 검증은 다음 방식으로 진행한다.
- `npm run build` 통과 확인
- 개발 서버에서 브라우저로 직접 확인 (Chrome DevTools의 위치 오버라이드 기능으로 GPS 허용/차단 케이스 테스트)
- 확인 항목: 계정 생성/로그인, 지도 마커 표시, 거리 게이팅(허용/차단), 사진 업로드, 코멘트 공개 노출, 스탬프북 진행률, 완료 화면

## 사전 준비물
- 카카오맵 JavaScript API 키: 사용자가 [카카오 디벨로퍼스](https://developers.kakao.com)에서 앱을 등록하고 발급받아야 한다. 발급 절차는 구현 계획 단계에서 안내한다.
- 부평 지역 실제 스탬프 장소 목록(이름/주소/좌표): 아직 없으므로 예시 3~5곳으로 시작하고, 추후 Supabase 대시보드에서 직접 교체한다.

- 사진/코멘트 신고 및 모더레이션
