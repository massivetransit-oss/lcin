# React + Vite + Supabase Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold a Vite + React + TypeScript app in the project root with a Supabase client wired to the real `Localized Curricullum in BP` project, rendering only the title "지역바로알기".

**Architecture:** Standard Vite `react-ts` template. A single `src/lib/supabaseClient.ts` module creates and exports a Supabase client configured from Vite env vars. `App.tsx` is trimmed to render just the title — no data fetching, routing, or styling library.

**Tech Stack:** Vite, React 18, TypeScript, `@supabase/supabase-js`, npm.

## Global Constraints

- Package manager: npm (exact commands below use `npm`)
- Vite template: `react-ts`
- Supabase project: `Localized Curricullum in BP`, ref `nqnfuyyjlwgzbctumxxv`

- Supabase publishable key: `sb_publishable_l7xR1aihgPGYafdzj8juMw_tC43utnd`
- Title text must be exactly: `지역바로알기`
- `.env` must never be committed to git; `.env.example` (no real values) is committed instead
- No database queries, auth, routing, or styling libraries in this scope
